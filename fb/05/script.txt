Website won't load, but everything else works?
Try this one command.
Your PC keeps a list of website addresses, called the DNS cache.
If an entry goes bad, that site can fail to load.
Click Start and type CMD.
Right click Command Prompt and choose Run as administrator.
Type ipconfig, space, slash flushdns, then press Enter.
You should see, Successfully flushed the DNS Resolver Cache.
Now reload the website.
It's safe, it only clears that saved list, and Windows rebuilds it as you browse.
