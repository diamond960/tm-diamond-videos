## 10 Command Prompt commands
These ten Command Prompt commands can fix your internet, repair broken Windows files, and close a frozen app in seconds.
You don't need to be a programmer, and you don't need to install anything.
I'll run every single one on a real Windows PC, so you can see exactly what you type and what you get back.
I'll also tell you which ones need administrator rights, and which ones you should be careful with.
And stay to the end, because one command can update almost every app on your PC at once.
## Open Command Prompt
First, let's open Command Prompt.
The fastest way is to press Windows and R together.
Type C M D, then press Enter.
For a few commands in this video, you need Command Prompt as an administrator.
For those, open Start and search for Command Prompt.
Then click Run as administrator on the right.
If Windows asks for permission, click Yes.
## 1. ipconfig /flushdns
Command number one is for when a website won't load, but everything else works.
Windows keeps a list of website addresses it has looked up before, called the DNS cache.
If an entry in that list is old or wrong, a site can fail to open.
Type ipconfig, space, slash, flushdns, and press Enter.
Windows replies that it successfully flushed the DNS resolver cache.
Now try the website again.
This is completely safe, because Windows simply looks the addresses up again.
## 2. ipconfig
Command number two shows your PC's network address.
Just type ipconfig and press Enter.
Look for the line that says IPv4 Address.
That number is your PC's address on your local network.
Right under it, you can also see the subnet mask and the default gateway.
The default gateway is usually the address of your router.
You will need these numbers when you set up a printer, or when someone helps you fix your network.
## 3. ping
Command number three tells you whether your PC can reach another device.
Type ping, a space, then an address, and press Enter.
Let's start with one hundred twenty seven, dot zero, dot zero, dot one.
That special address is your own computer, so it is a quick test of your PC's network software.
Every line that says Reply from means the message came back.
At the bottom, you see how many were sent, how many came back, and how long they took.
Now look at a ping to google dot com.
Here every line says Request timed out, and one hundred percent of the packets were lost.
That means no replies came back.
Your connection could be down, but some networks and firewalls also block ping on purpose, like this one.
So use ping as a clue, not as the final answer.
To keep pinging nonstop, add space, dash t, and press Control and C to stop it.
## 4. sfc /scannow
Command number four repairs broken Windows system files.
If Windows crashes, freezes, or acts strangely, this is the one to try.
It needs Command Prompt as an administrator.
Type sfc, space, slash, scannow, and press Enter.
Windows checks every protected system file and replaces the damaged ones.
It can take a while, so keep the window open until verification reaches one hundred percent.
On this PC, it found corrupt files and successfully repaired them.
If it repaired anything, restart your PC.

Okay, we're halfway, and the next command shows everything about your PC in one screen.
## 5. systeminfo
Command number five is systeminfo.
Type systeminfo and press Enter, then wait a few seconds while it collects the details.
You get your Windows version and build number, your processor, and when Windows was installed.
Further down, you see your total physical memory, and your network cards.
This is perfect when you want to check if your PC can run a game or an app.
## 6. tasklist and taskkill
Command number six is really two commands, and they close an app that won't respond.
Here, Notepad is open.
Type tasklist and press Enter, and you get every program running on your PC.
Find the name of the app, here it is notepad dot exe.
Now type taskkill, space, slash I M, space, the app name, then space, slash F.
Slash F means force, so Windows closes it even if it's frozen.
Windows says the process has been terminated, and Notepad is gone.
Be careful, because anything you didn't save in that app is lost.
## 7. winget upgrade
Command number seven is the one I promised at the start.
Type winget, space, upgrade, and press Enter.
The first time, it may ask you to accept the source agreements, so type Y and press Enter.
Winget is the Windows Package Manager, and it lists the apps on your PC that have a newer version.
You see the name, the version you have, and the version that is available.
To update all of them in one go, type winget upgrade, space, dash dash all.
Winget then downloads and installs each update, one after another.
Some apps may ask for permission or need to be closed first, so save your work before you run it.
## 8. chkdsk
Command number eight checks your drive for errors.
Open Command Prompt as an administrator, type chkdsk, space, C colon, and press Enter.
Without any extra options, it only scans and reports, it doesn't change anything.
On this PC it took a little over five minutes.
At the end, it says Windows has scanned the file system and found no problems.
You can also see zero kilobytes in bad sectors, which is what you want to see.
If it does find errors, run chkdsk C colon slash F to fix them.
For your main drive, Windows will offer to run it the next time you restart.
## 9. driverquery
Command number nine is driverquery.
Type driverquery and press Enter.
You get a list of every driver installed on your PC.
Drivers are the small programs that let Windows talk to your hardware, like your graphics card or Wi-Fi.
Each line shows the driver's name, its type, and its date.
It's a quick way to check what is installed before you update or troubleshoot a device.
## 10. shutdown timer
Command number ten turns your PC off on a timer.
Type shutdown, space, slash S, space, slash T, space, and then the number of seconds.
Here, thirty six hundred seconds is one hour.
Windows schedules the shutdown, and you can keep working until then.
Changed your mind?
Type shutdown, space, slash A, and press Enter.
Slash A means abort, and the scheduled shutdown is cancelled.
If you run it a second time, Windows says there is no shutdown in progress, so you know it worked.
That's all ten commands, and every one of them is already built into Windows.
