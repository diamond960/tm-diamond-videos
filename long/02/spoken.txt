Is your Windows PC slow to start, slow to open apps, or freezing for no reason?
In this video, I'll show you ten fixes on a real Windows PC.
Every fix is free, and none of them deletes your files.
Most of them take less than a minute.
And stay to the end, because fix number seven frees up space without deleting anything you need.
Let's start with the one that makes the biggest difference.
Many apps start by themselves every time you turn on your PC.
Each one makes startup slower and keeps using memory in the background.
Press Control, Shift, Escape to open Task Manager.
On the left, click Startup apps.
Here you can see every app that starts with Windows, and its startup impact.
This one is called HeavyApp, and it starts every time.
Select it, then click Disable at the top.
The status now says Disabled.
The app still works, it just won't start by itself anymore.
Do this for every app you don't need right away, like chat apps, updaters and game launchers.
If your PC is slow right now, something is using your processor or memory.
Open Task Manager again, and stay on Processes.
Click the CPU column to sort by what is working hardest.
Look at the app at the top.
Here, HeavyApp is using almost half of the processor.
Click Memory to check that column the same way.
If you don't need the app, save your work, select it and click End task.
Look at the CPU total now, it dropped right down.
Sometimes the taskbar, the Start menu or File Explorer freezes.
You don't need to restart the whole computer.
In Task Manager, find Windows Explorer in the list.
Select it, then click Restart task at the top.
The taskbar disappears for a second and comes back fresh.
Your open apps stay open.
Here is a hidden setting that makes frozen apps easy to close.
Open Settings, then System, then For developers.
Turn on End task.
Now right-click any app on your taskbar.
You get a new option called End task.
Click it, and the app closes right away, even if it's frozen.
No more opening Task Manager every time.

Now, the next two fixes make Windows feel faster straight away.
Windows uses animations and see-through effects on menus and windows.
They look nice, but they use your graphics and processor.
Open Settings, then Accessibility, then Visual effects.
Turn off Animation effects.
Then turn off Transparency effects.
Menus and windows now open without the fade and slide.
There is an older setting that goes even further.
Search for performance in the Start menu, and open Adjust the appearance and performance of Windows.
In this window, select Adjust for best performance.
This turns off the extra visual effects all at once.
Click OK to apply it.
Windows looks a little plainer, but it responds faster on older PCs.
Now the fix I promised.
Windows keeps temporary files that you don't need anymore.
Open Settings, then System, then Storage.
Click Temporary files.
Windows shows how much space each kind of file uses.
On this PC, the selected files add up to four hundred and seventeen megabytes.
Tick the ones you don't need, then click Remove files.
Click Continue to confirm.
Be careful with the Downloads folder, because it can contain files you still want.
You don't have to clean up by hand every time.
Go back to Storage, and open Storage Sense.
Turn on automatic user content cleanup.
Now Windows deletes temporary files for you.
You can also choose how often it runs, for example every week, or when disk space is low.
Old apps take up space, and some of them run in the background.
Open Settings, then Apps, then Installed apps.
Set Sort by to Size, large to small, so the biggest apps are at the top.
Click the three dots next to an app you don't use.
Then choose Uninstall.
Only remove apps you recognize and don't need.
The last fix keeps your drive running smoothly.
Search for defragment, and open Defragment and Optimize Drives.
Select your C drive.
Click Optimize.
On a hard drive, Windows rearranges the files so they load faster.
On an SSD, Windows sends a trim command instead, which keeps it fast.
Windows normally does this every week, but it's worth checking it is turned on.
Those are ten free fixes for a slow Windows PC.
Start with startup apps and temporary files, they make the biggest difference.
