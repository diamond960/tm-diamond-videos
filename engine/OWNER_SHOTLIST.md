# What the owner records for the Claude parts (Claude needs his login)

How: record the screen on your phone (Claude app) or computer (claude.ai), 20-60 seconds, no talking needed
(the voice is added later). Keep it slow: tap, wait for the answer to finish, scroll a little.
Before you record: close other chats in the sidebar you don't want seen, or use a fresh chat.
Put each file in your Google Drive folder "TM_Diamond footage", named with the part number first, e.g.
"part7 claude.mp4". The daily task copies it in and makes the part.

- part7 - Claude vs ChatGPT, same prompt: in Claude type exactly
  "Give me 3 YouTube titles for a video about fixing a slow laptop" and let the full answer show.
  (ChatGPT gets the same prompt on the capture PC.)
- part8 - How to start with Claude for free: open Claude, tap New chat, type
  "Explain what you can help a YouTube creator with, in 5 short bullet points", let it answer.
- part9 - How I use Claude to edit my videos: in a chat where Claude edits or captions one of your
  videos with a connected app (Descript, OpusClip...), record asking for it and the finished result.
- part10 - How I use Claude to post: record asking Claude to post a finished video, and the
  "posted" reply with the link (scroll to show the post if you can).
- part11 - Claude vs ChatGPT for beginners: in Claude ask these three, one after another:
  "Write a 2-line Instagram caption for a tech tip video", "Explain RAM like I'm 10",
  "Make a 3-day posting plan for a tech channel as a table".
